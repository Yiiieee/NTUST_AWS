# 🚪 智慧人臉辨識門鎖系統 (Smart Face Recognition Door Lock)

這是一個基於 **電腦視覺 (Computer Vision)** 與 **物聯網 (IoT)** 技術的智慧門鎖系統。系統採用邊緣計算架構，將繁重的 AI 影像辨識運算交由效能較好的 PC 處理，並由 Raspberry Pi (樹莓派) 負責即時影像串流與實體馬達控制。同時整合了 Supabase 提供雲端監控與闖入者日誌記錄。

---

## 🌟 系統特色

*   🖐️ **手勢喚醒機制**: 使用 MediaPipe 偵測手勢，伸出「1」根手指即可喚醒人臉辨識系統，避免系統持續進行耗能的臉部比對。
*   👤 **高精度雙重人臉辨識**:
    *   第一階段：使用 **ArcFace** 進行快速且高精度的初步比對。
    *   第二階段：若初步比對有些微誤差，自動啟用 **Facenet** 進行二次確認。
    *   自動學習：對於極高置信度的辨識結果，系統會自動將特徵存入白名單，提升未來辨識率。
*   ☁️ **雲端同步與離線快取**: 偵測到陌生人闖入時，系統會自動拍照並上傳至 Supabase 雲端資料庫。內建 SQLite 離線快取機制，斷網時資料不會遺失，網路恢復後自動背景補傳。
*   🚀 **低延遲影像串流**: 樹莓派端對影像進行降解析度與壓縮，透過 TCP 穩定傳送即時畫面至 PC。
*   ⚙️ **硬體控制**: 驗證成功後，PC 傳送指令至樹莓派驅動步進馬達 (28BYJ-48) 完成開鎖動作。

## 🏗️ 系統架構

1.  **Raspberry Pi (終端設備)**
    *   🎥 擷取攝影機畫面，並將 JPEG 影像串流傳送給 PC (`pi_stream_client.py`)。
    *   ⚙️ 監聽 PC 傳來的控制指令，驅動步進馬達 (`pi_motor_server.py`)。
2.  **PC 端 (運算中心)**
    *   🧠 接收影像，執行 MediaPipe 手勢偵測與 DeepFace 人臉辨識 (`pc_gesture.py`)。
    *   ☁️ 處理資料雲端備份與本地快取 (`cloud_sync.py`)。
3.  **Supabase (雲端資料庫)**
    *   🗄️ 儲存闖入者的照片 (Storage) 與紀錄 (Database)。

## 🛠️ 環境需求與安裝

### 硬體需求
*   **PC**: Windows / Linux / macOS (需有足夠效能跑 DeepFace 模型)
*   **Raspberry Pi**: 建議 Pi 3 或 4
*   **相機**: USB Webcam (連接至樹莓派，若無樹莓派連線，PC 端程式會自動 Fallback 使用本機相機)
*   **馬達**: 28BYJ-48 步進馬達 + ULN2003 驅動板

### 軟體與套件需求 (PC 端)
請確保您已安裝 Python 3.8+，並安裝以下套件：
```bash
pip install opencv-python numpy mediapipe deepface supabase
```

### 軟體與套件需求 (樹莓派端)
```bash
pip install opencv-python RPi.GPIO
```

## 🚀 設定與執行步驟

### 第一步：初始化 Supabase (PC端)
1. 確保 `setup_supabase_v2.py` 和 `cloud_sync.py` 裡面的 `SUPABASE_URL` 與 `SUPABASE_KEY` 已經設定為您的專案憑證。
2. 執行初始化腳本建立資料表：
   ```bash
   python setup_supabase_v2.py
   ```

### 第二步：設定白名單照片 (PC端)
在專案目錄下建立 `owners` 資料夾（若無），並將允許開鎖的人臉照片（`.jpg` 或 `.png`）放入該資料夾中。照片盡量保持臉部清晰、光線充足。

### 第三步：設定 IP 地址
請根據您當下的網路環境，修改程式碼中的 IP 設定：
*   **`pc_gesture.py`**: 修改 `PI_IP` 為您的**樹莓派 IP**。
*   **`pi_stream_client.py`**: 修改 `PC_IP` 為您的 **PC IP**。

### 第四步：啟動樹莓派端程式
SSH 進入您的樹莓派，開啟兩個終端機分別執行：
1.  **啟動馬達控制伺服器** (預設監聽 Port 65432):
    ```bash
    python pi_motor_server.py
    ```
2.  **啟動影像串流客戶端** (預設傳送至 PC Port 65434):
    ```bash
    python pi_stream_client.py
    ```

### 第五步：啟動 PC 端主程式
在 PC 端執行主程式：
```bash
python pc_gesture.py
```
> **💡 提示**: 程式啟動時會載入 DeepFace 的模型，第一次執行可能需要一些時間下載模型權重檔，請耐心等候。

## 🎮 使用指南

1.  **系統啟動**：PC 畫面會顯示接收到的樹莓派即時影像（畫面上方會顯示 Source: Raspberry Pi）。畫面上會有一個綠色的框，提示「Put Face Here」。
2.  **手勢喚醒**：請站在鏡頭前，將臉部對準綠框，並對著鏡頭舉起**一根手指頭**（比出數字 1 的手勢）。
3.  **身分驗證**：
    *   偵測到手勢後，系統會擷取綠框內的影像進行影像增強 (CLAHE) 並進行臉部比對。
    *   **✅ 驗證成功**: 畫面顯示 `ACCESS GRANTED`，PC 會發送訊號給樹莓派，樹莓派將轉動馬達開鎖。
    *   **❌ 驗證失敗**: 畫面顯示 `ACCESS DENIED`，系統會拍下闖入者照片儲存至 `intruders` 資料夾，並於背景非同步上傳至 Supabase。
4.  **關閉系統**：在 PC 顯示畫面的視窗中按下鍵盤 `q` 鍵即可安全關閉程式。

## ⚠️ 常見問題與除錯 (Troubleshooting)

*   **無法連線到樹莓派影像或馬達**
    *   請確認 PC 與樹莓派是否連接在同一個區域網路 (Wi-Fi)。
    *   檢查 IP 地址是否設定正確。
    *   確認 Windows 防火牆是否阻擋了 Python 或 Port `65432` / `65434`。
*   **RPi.GPIO 無法載入 (樹莓派端)**
    *   如果您在非樹莓派的環境下執行 `pi_motor_server.py` 會出現此警告。如果在樹莓派上出現，請執行 `sudo apt-get install python3-rpi.gpio`。
*   **Supabase 上傳失敗**
    *   檢查 `SUPABASE_URL` 與金鑰是否正確。
    *   不用擔心資料遺失，`cloud_sync.py` 會將資料寫入本地 SQLite (`cloud_sync_cache.db`)，並在背景不斷重試上傳直到成功為止。
*   **人臉辨識一直失敗**
    *   確認 `owners` 資料夾中有照片。
    *   確保測試環境光線充足，避免背光。系統會在偵測時提示影像是否過於模糊。
