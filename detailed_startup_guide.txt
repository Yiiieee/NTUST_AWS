      流程指南

「樹莓派端 (負責傳送影像與控制馬達)」以及「PC 電腦端 (負責跑 AI 手勢與人臉辨識)」兩個部分。


### 準備工作：確認樹莓派的 IP 地址
在開始之前，您必須先知道樹莓派連上網路後的 **IP 地址**。
1. 將樹莓派連上與您電腦相同的 Wi-Fi 或區域網路。
2. 在樹莓派的終端機輸入 `hostname -I` 或 `ifconfig`，找到它的 IP 地址 (例如：`192.168.1.100`)。
3. **請記下這個 IP 地址，後續的設定都會一直用到它。**

---

### 第一階段：樹莓派端設定 (Raspberry Pi)
請在您的樹莓派上執行以下步驟。

**1. 硬體接線確認**
*   相機鏡頭： 確認已正確接上樹莓派的 Camera 介面。
*   步進馬達 (28BYJ-48) 與 ULN2003 驅動板： 
    - IN1 接 GPIO 17 (Pin 11)
    - IN2 接 GPIO 18 (Pin 12)
    - IN3 接 GPIO 27 (Pin 13)
    - IN4 接 GPIO 22 (Pin 15)
    - VCC 接 5V (Pin 2 或 4)
    - GND 接 GND (Pin 6)

**2. 啟動相機的影像串流 **
需要開啟樹莓派的相機，並將影像轉換為一個網址供電腦讀取。
*   開啟樹莓派終端機，輸入以下指令啟動串流服務：
    mjpg_streamer -i "input_uvc.so -d /dev/video0 -r 640x480 -f 30" -o "output_http.so -w /usr/local/share/mjpg-streamer/www -p 8080"
*   您的影像網址 (STREAM_URL) 將會是： 
    http://<您的樹莓派IP>:8080/?action=stream
    (例如，如果您的樹莓派 IP 是 192.168.1.100，那網址就是 http://192.168.1.100:8080/?action=stream)

**3. 啟動馬達伺服器程式**
用來接收電腦傳來的「開門」訊號。
*   確認 `pi_motor_server.py` 已經放在樹莓派中。
*   打開另一個樹莓派終端機視窗，執行：
    python3 pi_motor_server.py
*   此時樹莓派會顯示正在監聽 `0.0.0.0:65432`，等待電腦連線。

### 第二階段：PC 電腦端設定與執行 (VSCode)
請回到您的 Windows 電腦上，打開 VSCode。

**1. 修改 PC 端的連線設定 **
打開 `c:\Users\h0928\OneDrive\桌面\VScode\AWS\pc_gesture.py`，找到大約第 10 行的參數設定區，將 `192.168.x.x` 替換成您剛剛查到的真實樹莓派 IP 地址。

# ================= 參數設定 =================
PI_IP = '192.168.1.100'  # ← 把這裡改成你的樹莓派 IP 地址
PI_PORT = 65432

# tcp 串流
STREAM_URL = 'http://192.168.1.100:8080/?action=stream' # ← 把這裡改成你的樹莓派 IP 地址

**2. 設定白名單 **
*   前往資料夾：`AWS\owners\`
*   確保裡面至少有一張清晰的臉部照片 。只有放在這裡面的人，比出手勢 1 才能夠開門。

---

### 系統完整運作流程體驗
當兩邊都成功啟動後，系統會這樣運作：
1. 成功連線： PC 的終端機會顯示「成功連線至樹莓派 <您的IP>:65432」，並且會彈出一個視窗，顯示樹莓派鏡頭拍到的即時影像。
2. 手勢辨識： 將手放到鏡頭前，畫面上會畫出骨架，並顯示您伸出了幾根手指 (Fingers: X)。
3. 觸發人臉辨識： 當您對著鏡頭比出數字 1 (只伸出食指)，系統會啟動臉部驗證機制。
4. 驗證結果：
   * 成功 (ACCESS GRANTED)： 您的臉與 `owners` 資料夾中的照片相符。電腦會發送訊號 `1` 給樹莓派，樹莓派終端機顯示「收到指令: 1」、「馬達開始轉動」，接著馬達轉動開門。
   * 失敗 (ACCESS DENIED)： 您的臉不在白名單內。馬達不會動，且系統會自動將您的照片拍下來，存到 `AWS\intruders\` 資料夾中作為闖入者紀錄。

遇到問題排解：
* 如果電腦畫面打不開： 請將您瀏覽器打開，輸入 http://<您的樹莓派IP>:8080/?action=stream 看是否能看到畫面，如果不行，代表樹莓派的 mjpg-streamer 沒有成功啟動或 IP 填錯了。
* 如果無法連線到樹莓派 (連線逾時)： 請確認樹莓派的 pi_motor_server.py 有在執行，並且確認電腦與樹莓派連接著同一個 Wi-Fi 網路。
